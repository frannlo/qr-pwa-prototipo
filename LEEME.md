# Prototipo QR (descartable)

1. Subir esta carpeta a un repo nuevo (ej. `qr-pwa-prototipo`) y activar GitHub Pages
   (Settings > Pages > rama main, carpeta raíz). Queda en https://TU-USUARIO.github.io/qr-pwa-prototipo/
2. Notebook: abrir `/pantalla.html`, tocar «Activar sonido», subir el brillo al máximo.
3. Android (Chrome): abrir `/escaner.html`, tocar «Abrir cámara», apuntar al monitor.
4. Instalar: menú ⋮ > «Instalar app» / «Agregar a pantalla principal». Repetir la prueba desde el ícono.
5. Casilla «Simular cuota vencida» para probar el rechazo con «pip pip».

Anotar en cada prueba: tiempo hasta leer, si pide permiso de cámara cada vez,
distancia máxima, comportamiento con poca luz y con reflejos en el monitor.
